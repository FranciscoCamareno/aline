# Textos de licencia de terceros

Textos oficiales que los paquetes no incluyen y que deben acompañar a la aplicación compilada:

- `excalidraw.LICENSE.txt`: licencia MIT de Excalidraw, copiada de https://github.com/excalidraw/excalidraw/blob/master/LICENSE (el paquete npm no la incluye).
- `OFL-1.1.txt`: SIL Open Font License 1.1, para las fuentes del lienzo con esa licencia.

`scripts/third-party-notices.ts` los combina con las licencias de cada dependencia y con los avisos de copyright de cada fuente para generar `THIRD-PARTY-NOTICES.txt`.
